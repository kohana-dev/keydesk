# Cellar app icon

Original blue/violet ribbon wine-opener artwork created for Cellar with AI image generation, distributed under the repository MIT license.

`Cellar-source.png` is the unmasked opaque square master. `Cellar.icns` is the ten-slot macOS raster icon, including transparent external margins and rounded enclosure. The build copies it and sets CFBundleIconFile. This is a static icon, not a layered Icon Composer Liquid Glass asset.

The light appearance is the released default. Design experiments and private screenshots are excluded from public source.
