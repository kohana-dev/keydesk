# 공개 준비 상태 · 2026-10-11

공개 릴리스 소스 기준 0.5.5 beta. 개인 실사용 앱의 키 값과 복구 키는 이 작업에서 읽지 않았다.

## 완료

- 전체 Swift 검사 65개 통과: 작업 폴더와 공개 소스 패키지에서 각각 확인.
- 잠자기·세션 비활성 알림 처리 및 wake 뒤 잠금 유지 회귀 검사.
  이는 알림을 테스트 프로세스에 전달한 검사이며 실제 OS 잠자기 증거는 아니다.
- 설치본 서명된 CLI 인증, 승인 없는 조회 거부, 서명되지 않은 피어 차단 재확인.
- 공개 패키지의 데모 빌드, 사용자 정의 Bundle ID 빌드와 CLI 서명 ID 일치.
- 배포 도구 부정 사례 5개, 공개 패키징 부정/정상 검사 2개 통과.
- 공개 소스의 프로토콜 및 터미널 종료 복원 10개 사례 통과.
- MIT 코드 라이선스, 기여 안내, 보안 제보 정책, 타사 아트워크 출처·고지.
- GitHub 공개 저장소 생성 및 비공개 취약점 제보 활성화.
- 공개 릴리스 소스 커밋의 원격 CI 성공: https://github.com/kohana-dev/keydesk/actions/runs/38140869523
- Apple 공증 Accepted, 티켓 첨부·Gatekeeper 검사 완료 후 v0.5.5 베타 공개.
  https://github.com/kohana-dev/keydesk/releases/tag/v0.5.5
- 공개 소스에서 개인 검증 자료, Git 이력, 인증서·프로필·실제 금고 배제.
  허가가 확인되지 않은 사이트 이미지 2개 제외; 55개 브랜드 소스 해시 확인.
- 개인 금고 iCloud 업로드 완료 확인. 암호화 백업 로컬 사본 준비 및 바이트 일치 확인.

## 공개 전/기기에서 남은 확인

1. 향후 변경마다 CI를 확인하고 공개 배포는 서명·공증·다운로드 검사를 유지.
2. 공식 서명·공증 바이너리와 해시는 GitHub v0.5.5 릴리스에서 제공한다. Apple Silicon 전용.
3. 다른 Mac의 설치·iCloud Keychain 동기화·복원. 같은 Mac 격리 복원은 기존 검사로 통과.
4. 실제 화면 잠금·잠자기 및 운영 환경 OS 인증 취소. 자동 검사와 구분.
5. 로컬 암호화 사본을 외장 저장장치 등으로 옮기고 복구 키를 직접 별도 보관.
6. 독립 보안 감사는 수행하지 않았다. 공개한다면 베타 상태와 검증 한계를 명시한다.

공개 대상은 `scripts/export-public-source.py`가 생성한 소스 패키지이다.
이 작업 폴더 전체 또는 과거 Git 객체를 그대로 올리는 방식은 사용하지 않는다.
