# Third-party artwork

The MIT license for Keydesk does not license service trademarks. Artwork is
used only to identify services, with no endorsement implied. There are no
external Swift package dependencies. System frameworks are supplied by Apple.

- Simple Icons: CC0-1.0, bundled SimpleIcons-LICENSE; individual brand rights and
  any per-icon licenses still apply. Sources and hashes are in the manifest.
- Lobe Icons: MIT, bundled LobeIcons-LICENSE with upstream attribution.
- Restic repository artwork: BSD-2-Clause, bundled Restic-LICENSE.
- Android robot: created and shared by Google, used under CC BY 3.0; SVG was
  rendered to PNG without changing the shape. Attribution: Google / Android.
  https://developer.android.com/distribute/marketing-tools/brand-guidelines
  https://creativecommons.org/licenses/by/3.0/

The local workspace contains Postmark and Amplitude website touch icons whose
redistribution permission has not been established. The public export omits
both source and rendered files and their manifest entries. Those services
remain selectable and display text initials. Do not redistribute the private
workspace asset folder as if all contents were MIT.
